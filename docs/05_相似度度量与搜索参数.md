# 05 相似度度量与搜索参数

## 1. 度量的数学定义

设查询向量为 `q`，候选向量为 `x`：

```text
余弦相似度  cos(q, x) = (q · x) / (|q| × |x|)
内积        ip(q, x)  = q · x
欧氏距离    L2(q, x)  = sqrt(Σ(qᵢ - xᵢ)²)
```

关系：

- 若 `|q| = |x| = 1`，则 `cos(q, x) = ip(q, x)`；
- `L2² = |q|² + |x|² - 2(q·x)`，所以对归一化向量，L2 排序与内积排序一致（方向相反）。

## 2. 怎么选度量

| 场景 | 推荐 | 原因 |
|---|---|---|
| 文本 embedding（多数模型已归一化） | COSINE 或 IP | 关注方向 |
| 推荐系统（向量模长有含义） | IP | 保留热度/权重信息 |
| 图像/音频特征 | L2 | 关注绝对差异 |
| 已确定向量全部单位化 | IP（更快） | 与 COSINE 等价 |

**最重要的一条**：索引声明、搜索参数、写入向量必须使用同一套度量。
不要建 COSINE 索引却传 L2 的 `search_params`。

## 3. 搜索参数

MilvusClient 的搜索接口大致形状：

```python
results = client.search(
    collection_name="docs",
    data=[query_vector],
    anns_field="embedding",
    limit=5,
    filter='category == "美食"',
    output_fields=["title", "category"],
    search_params={"metric_type": "COSINE", "params": {"ef": 64}},
)
```

- `limit`：返回 Top-K；
- `offset`：跳过前 N 条，用于分页；
- `filter`：标量过滤表达式；
- `output_fields`：返回哪些标量字段（向量默认不返回）；
- `search_params`：索引相关参数（`ef`、`nprobe`、`radius`、`range_filter` 等）。

分页注意：

- `offset + limit` 有上限（Milvus 常见上限为 16384），深分页应使用查询迭代器；
- 每次翻页都重新执行 ANN，页码越深成本越高；
- 需要稳定排序时，按“分数 + 主键”组合排序（本项目在 demo 中按分数展示）。

## 4. 范围搜索（Range Search）

不是取固定 Top-K，而是取“分数落在某个区间”的所有结果：

```python
search_params = {
    "metric_type": "COSINE",
    "params": {"radius": 0.6, "range_filter": 0.9},
}
```

方向很关键：

| 度量 | 返回区间 | 记忆 |
|---|---|---|
| L2 | `range_filter <= distance < radius` | 距离越小越好，区间在“近端” |
| IP / COSINE | `radius < score <= range_filter` | 分数越大越好，区间在“高端” |

写反了会得到空结果或错误结果。demo `09_search_advanced.py` 会打印实际分数范围帮助确认。

## 5. 带过滤的向量搜索

Milvus 支持 `search(filter=...)`，但有三个影响：

1. **召回率**：过滤后候选变少，固定 `ef`/`nprobe` 可能不够，需要适当增大；
2. **性能**：高选择性过滤可能退化为扫描；
3. **执行顺序**：不同版本/索引可能先过滤或先检索，结果数量可能少于 `limit`。

优化手段：

- 用分区裁剪把搜索范围限制在相关分区；
- 给高频过滤字段建标量 `INVERTED` 索引；
- 避免在过滤表达式中做复杂 JSON 深层路径匹配；
- 对“过滤后结果很少”的场景，考虑单独建子 collection。

## 6. 分数方向与展示

本项目在打印结果时保留原始分数：

- COSINE / IP：越大越相似；
- L2：越小越相似。

Gradio UI 会明确显示当前索引的度量与分数方向，避免误读。
