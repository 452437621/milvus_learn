# 00 学习路线与环境准备

## 1. 这个项目要解决什么问题

Milvus 的官方文档很全，但对初学者来说，最大的障碍往往不是概念，而是：

1. 没有 Docker / 服务器，跑不起 Standalone；
2. 没有 embedding 模型或 API Key，demo 卡在第一步；
3. 文档中的示例彼此独立，缺少一条从 CRUD 到混合检索、再到 RAG 的连续路径。

本项目用 **Milvus Lite（本地 `.db` 文件）** 解决第 1 点，用 **离线确定性伪向量** 解决第 2 点，
并用同一份 25 条中文语料把第 3 点串起来。所有脚本都能在本机离线运行。

> 伪向量只用于学习 Milvus 的用法。真实业务请替换为 BGE、OpenAI Embedding 等模型，
> 见 `mlcore/embedding.py` 中的 `get_embedder()`。

## 3. 环境说明

- 操作系统：Windows 10/11。
- Python：3.10 及以上（本项目在 3.14 上验证；若依赖 wheel 缺失，可用 3.12）。
- 依赖：
  - `pymilvus==3.0.3`：Milvus 官方 Python SDK。
  - `milvus-lite==3.2.2`：本地引擎，纯 Python 实现，支持 Windows。
  - `gradio`：交互式 Web UI。
  - `python-dotenv`：读取 `.env`。
  - `jieba`：中文 BM25 分析器（Milvus Lite 的 jieba analyzer 会动态导入）。

> **Windows 注意**：`pymilvus[milvus-lite]` 的 extra 带有 `sys_platform != "win32"` 标记，
> 在 Windows 上不会自动安装 milvus-lite。`requirements.txt` 已显式列出，请直接安装该文件。

## 4. 安装

在仓库根目录执行：

```bash
venv/Scripts/python.exe -m pip install -U pip
venv/Scripts/python.exe -m pip install -r requirements.txt
venv/Scripts/python.exe -m pip check
```

没有现成 venv 时：

```bash
python -m venv venv
venv\Scripts\python.exe -m pip install -r requirements.txt
```

安装后先运行环境体检：

```bash
venv/Scripts/python.exe demos/00_environment_check.py --deep
```

它会打印版本、关键方法签名、伪向量自检，以及 Milvus Lite 对 BM25、别名、分组搜索等能力的实测结论。
后续笔记中标注“Lite 可能不支持”的功能，以这个脚本的输出为准。

## 5. 数据目录与文件锁

每个 demo 使用独立目录：

```text
data/runs/01_hello/milvus.db
data/runs/03_crud/milvus.db
...
data/runs/ui/milvus.db       # Web UI
```

如果仓库路径包含中文（Windows 上 FAISS 无法写非 ASCII 路径），
上面的 `data/runs` 会自动替换为 `C:\Users\<用户名>\.milvus_learn_data\runs`。
无论哪种情况，不同 demo/UI 都使用独立数据目录。

原因：Milvus Lite 对同一个数据目录加**进程级文件锁**，两个进程同时打开同一个 `.db` 会失败。
独立目录让 demo、UI、冒烟脚本可以互不干扰，也方便随时删除重来。

`DemoSession` 在每次运行前会清空对应目录，因此 demo 是幂等的；运行数据已被 `.gitignore` 忽略。

## 6. 配置

不复制 `.env` 也能运行。需要修改时：

```bash
copy .env.example .env
```

常用配置：

| 变量 | 作用 |
|---|---|
| `MILVUS_URI` | 空 = 本地 Lite；填 `http://host:19530` = 远程 Milvus |
| `MILVUS_DB_DIR` | 本地数据根目录；留空时默认 `./data`，仓库路径含非 ASCII 字符则自动改用 `~/.milvus_learn_data` |
| `PSEUDO_EMBED_DIM` | 伪向量维度，默认 256 |
| `EMBEDDING_PROVIDER` | `pseudo`（默认）或 `openai` |
| `BM25_MODE` | `auto` / `native` / `manual` |
| `RAG_LLM` | `offline`（默认）或 `openai` |

切换远程 Milvus 时，demo 会给 collection 加 `learn_<demo>_` 前缀并在启动时清理，避免污染你的数据。

## 7. 运行方式

命令行：

```bash
venv/Scripts/python.exe demos/01_hello_milvus.py
venv/Scripts/python.exe demos/10_mini_rag.py --question "Milvus Lite 有哪些限制？"
```

PyCharm：

1. `File → Settings → Project → Python Interpreter` 选择 `.\venv\Scripts\python.exe`；
2. 右键脚本 → Run；
3. 入口脚本已在顶部把仓库根目录加入 `sys.path`，无需额外配置工作目录。

Web UI：

```bash
venv/Scripts/python.exe app/gradio_search.py
```

## 8. 常见问题

- **数据目录被锁**：关闭残留的 demo/UI 进程，或删除 `data/runs/<demo>` 后重试。
- **中文路径导致打开失败**：项目会自动把数据移到 `C:\Users\<用户名>\.milvus_learn_data`；
  也可在 `.env` 设置 `MILVUS_DB_DIR=C:/Users/<用户名>/milvus_data`。
- **控制台乱码**：项目已把 stdout 设为 UTF-8；仍异常时设置环境变量 `PYTHONIOENCODING=utf-8`。
- **安装失败**：先升级 pip，用 `--only-binary=:all:` 排查缺失 wheel；必要时改用 Python 3.12。
